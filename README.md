# Jogo da Velha em C

Este repositório contém o código de um Jogo da Velha clássico para jogar no terminal.

**Sobre o projeto:**
- Desenvolvido inteiramente na linguagem C.
- Projeto realizado durante o 1º período do curso de BCC.
- Objetivo: colocar em prática lógicas de programação, laços de repetição e matrizes.
